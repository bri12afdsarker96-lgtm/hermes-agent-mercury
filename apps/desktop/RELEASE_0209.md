# 企业助手 0.20.9 — 修复与在线发布记录

本版本修复 0.20.8 的窗口、布局和财务操作恢复问题。客户端基线为
`130d43f5ad426eaae15364f5a895162a8c5271c2`，兼容服务端
`2bec9611c3deea42d8229f5ad9e44956535d7761`，不要求修改服务端接口。

## 修复内容

- 登录、强制改密和工作台共用标题栏控制区预留逻辑。更新按钮随原生窗口
  按钮占用宽度向左避让；小窗口和页面缩放时仍可点击。
- 企业客户端原生窗口按钮固定为白色，深色标题栏不再被聊天主题覆盖。
- 显式设置窗口的任务栏身份、图标和重新启动信息。已安装客户端启动时，
  迁移属于本产品的旧桌面、开始菜单和固定任务栏快捷方式，保留启动参数。
- 小窗口登录页能够滚动到输入和提交区域；AI 输入及发送区域不再被内部
  固定高度裁切；应收款页面按容器收缩，宽表格保留自身横向滚动。
- 收款、冲销、任务操作的待确认请求写入持久化恢复记录，保留原请求编号
  和事实。旧的会话恢复记录在读取时迁移，存储失败时不发送财务写请求。
- 收款、改期和冲销的草稿、提交中及待确认状态接入更新保护和界面冻结。
  收款提交中不能关闭任务详情。
- 已成功提交的改期重试可正常解除待确认状态，并展示后续并发修改后的
  服务端最新日期。
