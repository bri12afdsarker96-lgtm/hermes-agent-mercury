# HarmonyOS Sans SC provenance

Hermes-企业助手 bundles the unmodified `HarmonyOS Sans SC` Light, Regular,
Medium and Bold font files for its desktop product interface.

- Source: Huawei's official HarmonyOS Sans download package.
- License: `../../src/fonts/LICENSE-HarmonyOS-Sans.txt`, copied verbatim from
  that package. The packaging contract installs the same notice at
  `resources/licenses/LICENSE-HarmonyOS-Sans.txt` with every distributed copy.
- Distribution boundary: the fonts are bundled only as part of Hermes-企业助手;
  they are not redistributed as a standalone font product.
- Notice: the product's About/legal surface must identify HarmonyOS Sans Fonts
  as an included font before a public release.

No font file or individual font component has been modified.
