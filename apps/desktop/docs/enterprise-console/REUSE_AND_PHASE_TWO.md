# 旧规划复用与本次交付范围

本表依据用户本轮要求、当前源码和 2026-09-05 的 GitHub 查询修订。原 `后续开发customer-conversation-extension-plan.md` 与 `HERMES_ACTION_HUB_DEVELOPMENT_PLAN.md` 保留为历史设计资料，其中的“未授权施工”、旧 PR 阶段和未来完成式表述不是当前实现证明。用户现已授权现成能力和小改动纳入交付，复杂设备与渠道项目留在二期。

## 本次复用

| 能力 | 当前真实基础 | 本次做法 |
| --- | --- | --- |
| 文本/语音问答、摘要、改写、待办提取 | `enterprise-client/assistant-page.tsx`、服务端 `enterprise/tenant_assistant.py` | 复用现有工作台；语音先转写为可编辑文本，提交后生成；补常用入口和文本成果导出。没有自动执行模型描述的动作。 |
| 六音色自然播报 | 已实测自有 Worker 的 speech 接口，六个声音均返回有效 MP3 | 平台统一提供基础能力，坐席无需填写 API 配置；音色、风格、语速按服务器/租户/坐席分区保存本机偏好。 |
| 百客户回复草稿 | 独立客户 ID、会话队列、服务端加密草稿与 CAS | 继续人工粘贴当前客户上下文、编辑/复制建议；不把生成、复制当作已送达。当前知识上下文供内部坐席参考，发送前需确认允许对客披露。 |
| 企业知识 | Candidate→Review→Publish、受控向量检索、下架与冲突处理 | 复用正式知识生命周期，替换历史 JSONL 查找；不让上传即变成已发布知识。 |
| 任务、提醒与人工接管 | `biz_tasks`、`reminders`、`biz_task_handoff` 与已有 HTTP/桌面面板 | 复用原状态机和权限；补便捷入口。AI 提取的文字不是已创建任务，提醒记录也不是已送达通知。 |
| 桌面更新 | 现有 NSIS 包、Electron main/preload 能力桥 | 接入成熟安装包更新库，提供检查、立即更新及下次启动预下载；旧源码 Git 更新不用于客户安装包。 |

## 二期项目

| 项目 | 保留的设计价值 | 仍需补齐的实质工作 |
| --- | --- | --- |
| 外部客户身份与关系同步 | Internal Principal 与 ExternalParty 分离，稳定 provider ID，关系撤销与审计 | 官方客户联系权限/回调、关系权威表、归属校验、重放与撤销验证。当前手工客户草稿 ID 不冒充官方客户身份。 |
| 客户完整会话与对外知识策略 | 复用 message ledger，External Audience Policy，未知送达不盲重试 | 真实渠道来源与发送权限、外部可见知识标签及强制检索限制、会话转交/接管。普通好友私聊不能通过微信客服接口替代。 |
| Android 与 Device Mesh | 单设备串行、多设备独立 attempt、急停、一次性配对、任务回执 | 设备身份/租约/审批、Keystore、签名 APK、真机弱网与权限恢复、远程画面和受控触控；不是打开现有页面即可交付。 |
| 多机电商巡检、客服值守、自动发布 | 场景约束与 Skills 复用、外部副作用需回执 | 平台权限、受限执行环境、逐动作审批、状态回收及真实业务验收。 |
| 自主浏览、编程、文档/图片生成与定时执行 | 上游 Hermes 已有 tools/skills/cron/artifacts | 当前企业文本助手尚未接入具备租户隔离的完整 agent 工具运行时；个人 Agent 的本机工具、密钥和文件权限不能直接共享给所有坐席。 |

## 已过时或需纠正的表述

- 两份旧文档的“直接交付”均是目标，不能据此宣称 Android Node、MCP 设备网关或所有插件 API 已完成。
- GitHub 中多个相关 PR 仍为 Draft；提交存在、旧 debug APK 或历史测试通过均不等于已合并并部署。实际交付以安装包版本、服务器版本和本次验收记录为准。
- `knowledge_rag`、身份迁移和 capability 等旧静态成熟度注释与部分已存在实现不完全同步；先验证实际路径及生产依赖，不能把所有 `DEV/CONTRACT` 批量改成 `LIVE`。
- 用户保持坐席好友私聊、拒绝昂贵存档的决策持续有效；不购买存档，不将微信客服入口作为当前私聊的替身。
- 不复制第二套身份、RAG、任务、提醒、Outbox、聊天或调度引擎。保留上游及同事代码归属；没有真实调用链的能力留在本表中，不以演示数据开放。

后续入口和导出的验收结果记录在交付指南；此表本身不证明功能已发布。
