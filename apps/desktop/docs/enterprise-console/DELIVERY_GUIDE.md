# Hermes-企业助手交付与使用指南

本指南对应企业客户端。安装包版本、下载地址、文件校验值与已启用服务以同批交付清单为准；本指南不是生产环境验收通过的替代证明。

## 首次使用

1. 从交付清单指定的地址取得 Windows 安装包，核对版本与文件校验值后安装。客户端按当前 Windows 用户安装；电脑的公司管理策略可能另外限制安装权限。
2. 使用管理员分配的企业账号登录。首次登录如要求修改密码，完成修改后进入工作台。不要在聊天、截图或工单中发送密码、登录令牌、模型密钥。
3. 核对当前企业和身份。看不到某项功能时，先确认管理员是否给该身份开放了功能；修改客户端界面不能增加服务端权限。
4. 企业管理员在企业 AI 配置中选择厂商、模型并保存密钥，设置默认模型。坐席和主管使用企业配置的模型池，不需要各自购买或输入模型密钥。

语音识别和朗读是基础语音服务；回答的推理与写作能力由企业实际配置的大模型决定。配置模型名称不等于连接成功，须完成一次真实问答。模型厂商额度不足或鉴权失败时会显示不可用，不会悄悄借用其他企业的密钥。

## 各身份负责什么

| 身份 | 主要工作 |
| --- | --- |
| 平台管理员 | 管理企业、企业状态及平台范围配置。平台管理身份不代表已经进入某个企业的业务工作区。 |
| 企业管理员 | 管理本企业成员、业务功能、模型池和连接配置；上传知识，按职责分离规则审核或发布。 |
| 主管 | 使用企业 AI 与知识问答，处理团队工作；可审核普通风险知识候选。 |
| 坐席 | 使用企业 AI、客户回复建议和已发布知识，处理分配的业务；不能配置模型密钥、审批或发布知识。 |

最终权限由服务端当前身份与企业功能开关共同决定。账号停用、企业停用或权限撤销后，旧窗口不能继续沿用旧权限。

## 同时处理多个客户

在「AI 助理 → 客户回复建议」中为客户建立独立工作区，使用便于核对的姓名、备注或业务编号。客户标签用于坐席辨认，不等于已验证的企业微信客户身份。

每个客户独立保存上下文、补充要求、生成状态和回复草稿。切换客户后，原客户的生成结果仍归原工作区；录音和识别结果也不得进入新客户输入框。不要把不同客户的聊天记录粘贴到同一个工作区。

日常操作顺序：选择客户 → 补充该客户最新上下文 → 生成建议 → 核对事实与收件人 → 复制 → 在企业微信原会话发送。「已复制」只表示复制成功，不表示客户已收到。

客户端最多维护 200 个客户工作区，草稿总量上限 2 MiB。完成的客户应及时整理或移除。右侧草稿出现「已保存到企业服务器」后，同一企业、同一账号重新登录可恢复；其他账号不能读取这份个人客户工作区。

如果出现保存失败，保持客户端打开并重试。多台设备同时编辑同一账号产生版本冲突时，本机修改不会覆盖服务器；先复制需要保留的文字，再读取服务器版本并合并。退出、重装、更新或重启前确认草稿已保存。普通企业对话的会话记录目前只保留在当前已登录客户端会话中，不承诺跨重启恢复。

「3 并发」指默认每个坐席同时进行的 AI 工作上限，服务端在同一服务实例内合并该坐席的多设备请求；企业默认总上限为 12。客户端还使用 3 路可见生成队列。管理员运维配置可以调整服务端限额；多实例扩容前需要共享限额方案，当前不能把进程内限额当作分布式额度。人工核对、复制和在企微发送不占用 AI 生成名额。

## 语音提问与六种音色

1. 在 AI 助理中选择「知识库问答」，点击「语音输入」，首次允许麦克风权限。
2. 说出问题，点击停止并等待转写。检查并修改识别文字后，再提交问题。
3. 系统使用当前企业的有效知识检索结果回答。可启用「语音提问后自动朗读回答」，也可对某条回答点击「朗读回答」。
4. 点击「停止朗读」可打断播报；开始新录音前会先停止旧播报，减少扬声器声音再次被录入。

在「播报方式、音色、语音风格、语速」中选择自己习惯的声音：

| 类型 | 名称 | 音色标识 |
| --- | --- | --- |
| 女声 | 晓晓 · 亲和女声 | `zh-CN-XiaoxiaoNeural` |
| 女声 | 晓伊 · 自然女声 | `zh-CN-XiaoyiNeural` |
| 女声 | 晓辰 · 清晰女声 | `zh-CN-XiaochenNeural` |
| 男声 | 云希 · 自然男声 | `zh-CN-YunxiNeural` |
| 男声 | 云健 · 沉稳男声 | `zh-CN-YunjianNeural` |
| 男声 | 云扬 · 清晰男声 | `zh-CN-YunyangNeural` |

音色、风格、语速和播报方式按「服务器、企业、坐席账号」保存在当前电脑；不同坐席互不影响，同一坐席换电脑需重新选择。这些偏好不包含客户文字或凭据。风格效果由当前语音服务及对应音色支持情况决定，不能保证每种音色都呈现相同程度的风格变化。

识别在企业服务器完成，默认单段最长 120 秒、最大 6 MiB，当前部署同时处理 1 段识别；忙碌时可稍后重试或继续文字输入。自然朗读将待播报文字发送到企业授权的语音服务，默认服务实例同时处理 3 个朗读请求。自然语音故障时，如电脑已安装可用中文系统语音，会显示提示并尝试系统朗读；系统音色数量和效果取决于电脑。没有可用声音仍可阅读文字回答。

当前服务器已完成真实中文录音小样：识别约 7 秒，单个推理进程约 750 MB。它是单次小样，不是所有录音的固定耗时或多人同时使用的承诺。

此版本采用按键录音、确认文字、提交问答的交互，不是全天候监听或免唤醒的电话系统。识别可能听错人名、金额、型号和日期，提交前应核对。

## 知识从上传到可回答

只有「已发布且当前有效」的知识参与知识库问答。上传成功、解析完成、审核通过都不等于已经可检索。

1. 企业管理员上传 TXT、MD、PDF、DOCX、CSV 或 XLSX，单文件不超过 50 MiB。先查看解析预览，检查是否缺字、乱码或表格拆分不正确。纯扫描件不保证有可用正文，应先整理成可复制的文字资料。
2. 点击「提交审核」，生成知识候选。一次提交最多 200 个切片；过长或切片过多时按提示拆分文件。
3. 由另一位有审核权限的人员核对内容。普通风险可由主管或企业管理员审核；高风险须由另一位企业管理员审核。作者不能审核自己的内容。
4. 审核通过后，由作者和审核人以外的企业管理员点击「发布知识」。发布失败或索引尚未完成时，按页面状态继续处理；未看到当前可检索状态前不要宣告上线。
5. 用坐席账号对知识提出一个近义问题，核对是否得到有依据的回答。原文复制粘贴命中不足以证明业务检索效果。

普通资料通常至少需要两位企业管理员与一位独立主管参与，分别承担作者、发布人和审核人；高风险内容可能需要三位不同企业管理员。不要通过共享账号、临时放宽权限或作者自审来绕过职责分离。

出现重复或冲突时，先比较候选与现有资料。界面提供保留现有资料、结束重复候选的处理；其他治理动作以当前明确开放的操作为准。旧版显示「已入库」的资料不会直接转为可用于 AI 的知识，应重新上传、审核并发布。

需要下线的内容可「撤回此知识」。撤回后不得用于新的知识检索；历史上已经展示、复制或发送过的回答不会被远程删除。资料更正应按正常审核发布流程重新提交。

未匹配到足够依据时，系统会明确说明。向量服务、身份权限或知识存储不可用时应显示失败或不可用，不能用无依据回答伪装成知识库答案。语义检索可能混淆相近规则，例如退货与换货；对外回复仍需人工核对。

知识库问答每次最多展示一个最直接相关的原文摘录，由服务器校验片段编号并保留完整摘录和条件；模型自行编写的报价、例外或操作说明不会作为知识答案直接显示。请核对平台、业务对象和处理阶段，尤其区分「客户签收商品」与「仓库签收退货」。显示相关原文不代表场景已经判断正确，也不代表系统已处理订单。无法选择可靠依据时会说明并提示补充信息；模型返回格式错误则显示生成不可用。

## 企业微信的实际接入范围

本期保留客户添加坐席企业微信好友、直接一对一聊天的原入口。客户端承担坐席辅助、知识检索、生成和整理回复，企业微信原会话承担实际收发。

普通企业微信好友私聊没有可供本项目任意读取全部聊天并代坐席持续自动发送的通用官方 API。本交付不包含绕过客户端的 Hook、抓取、外挂或模拟私聊消息收发，也不承诺复制后自动送达。官方侧边栏可用能力须满足该企业与当前会话的接口条件；配置入口不代表已经实现全量同步。

「会话内容存档」是另外开通和计费的能力；当前成本方案不以购买它为前提。「微信客服」是不同入口，如将来愿意让客户通过客服链接或二维码进入，可另行启用官方客服收发链路，不能自动把原好友私聊变成客服会话。租户的自动回复设置也不能突破所用渠道的官方收发边界。

## 故障处理与更新

| 现象 | 处理 |
| --- | --- |
| 无法登录、身份已失效 | 核对账号与网络；由管理员检查账号/企业状态。不要重复粘贴密钥。 |
| 没有模型或生成不可用 | 企业管理员核对本企业模型配置、厂商可用性和额度，完成真实问答后重试。 |
| 上传后搜不到 | 检查候选审核、独立发布和当前检索状态，再检查资料是否包含问题所需事实。 |
| 识别忙碌或失败 | 缩短录音，检查麦克风权限和输入设备，稍后重试；文字入口仍可用。 |
| 草稿保存失败或冲突 | 保持窗口打开，先保留本机必要文字，再重试或合并服务器版本。 |
| 更新下载或校验失败 | 保留当前版本，重新取得交付清单中的可信安装包；不要运行来源不明的替代包。 |

应用安装包更新与企业后台发布是两件事。所有角色使用同一客户端版本，下载或安装客户端不应授予服务器管理员权限。当前版本是否提供应用内检查/安装更新，以该批交付清单与界面为准；源码开发环境的 Git 更新入口不是企业安装包升级证明。

安装更新前先保存客户草稿，完成或结束正在进行的生成、录音和播报。更新后核对登录、客户工作区恢复、一次知识问答与一次语音往返。不要为更新清空应用数据或删除服务器知识数据库。

## 当前验证备注

本地 BGE 中文向量模型已经通过隔离小样及整份 140 卡片/175 候选问答库的正式发布、真实模型问答与撤回验收，模型文件约 98 MiB、小样测试进程峰值约 331 MiB。近似场景仍可能召回不适用摘录，需要人工核对。编写本指南时尚未切入生产；最终交付清单须单独确认实际启用的向量服务，不能把隔离验收当作生产知识问答已经上线。

## 交付验收建议

- 使用实际四种身份分别登录，核对可见功能和服务端操作权限；不能仅使用平台管理员完成验收。
- 使用不同企业和不同坐席核对数据隔离；验证同一坐席两台设备编辑草稿的冲突提示。
- 建立至少 100 个客户工作区，验证搜索、切换、乱序生成结果、草稿保存与重启恢复。
- 用三位独立人员完成上传、审核、发布，再用坐席检索；撤回后重新查询，验证内容不再命中。
- 使用近义问法和无答案问题验证知识依据；使用真实模型完成问答，不以离线假向量或模拟回复作为通过依据。
- 实测麦克风录音、文字确认、知识回答、六种自然音色、停止朗读和故障时文字继续可用。
- 取得安装包、版本和校验值，完成安装、启动、退出与重启验证；如提供应用内更新，再单独验证下载校验、失败保留旧版本和草稿恢复。
