# Hermes-企业助手交付施工清单

用户本轮明确授权继续完成项目、输出可交付 Windows 客户端，并要求科幻视觉和语音知识库交互。该要求覆盖旧资料中的 Desktop 视觉/语音范围限制；不引入未要求的 Android、飞书或员工评分功能。

## 交付范围

1. 原生中文账号登录与四角色工作台，租户模型池、员工、知识资料、客户辅助、任务/提醒和状态反馈。
2. 深色科幻视觉，HarmonyOS Sans SC，保持可读性、键盘操作、缩小窗口和减少动效模式。
3. 点击录音、停止转写、确认/修改问题、企业知识回答、语音播报与停止。音频必须经当前认证会话传输，切换客户/账号后旧转写不写入新上下文；模型密钥不交给 renderer。
4. 服务端控制单坐席跨设备与租户总并发，客户工作草稿持久恢复、版本冲突处理，知识读取经过发布/权限边界。
5. 保留普通企微好友私聊。Hermes 坐席辅助可交付；聊天工具栏按腾讯官方能力接入。不得声称已取得未开放的普通私聊全文同步或后台任意客户发送接口。
6. 服务端候选部署和真实认证链验证，Windows 安装包与校验和、安装/配置说明和验收记录。未持有代码签名证书时明确说明安装包签名状态。
