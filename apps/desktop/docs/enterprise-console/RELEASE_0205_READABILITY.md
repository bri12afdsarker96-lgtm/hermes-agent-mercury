# 0.20.5 回答卡片与阅读字号

针对 2026-09-11 的客户端截图反馈，基于已发布 0.20.4 迭代。

## 本轮修改

- 主回答、继续跟进、当前回复与备选回答统一使用 `AssistantReplyCard`。相同边框、背景、内边距与复制按钮，不再各自实现。
- 主回答显示“回答建议”标题；每张卡片只复制本卡片正文，不带检索摘要或其他卡片内容。
- 移除回答中的“保存为 Markdown”入口及文件下载处理。保留回答的 Markdown 排版，以及已有本地资料上传能力。
- 回答正文调为 16px；常规正文/导航 15px，表单与按钮标签 14px，辅助说明 13px。行高同步放宽。
- 将企业界面中 54 处固定小字号规则改为公共字号变量，覆盖工作台、问答、提醒、知识、员工与登录界面，不以全窗口缩放代替字体调整。
- 保留服务端的回答内容、模型、人设、权限与预发布网络配置；不更改生产业务数据。

## 验证

- 8 个相关交互测试文件、63 项测试通过：复制成功/失败、四语言标签、回答不重复、无 Markdown 下载按钮；应收款、账户安全、知识、提醒、在线更新回归。
- 客户端和端到端测试 TypeScript 检查通过，生产构建通过。
- 最终实际安装包验收 1 项通过（使用隔离的业务响应，不写生产数据）；包含长回答及 1024×768、1280×900、1920×1080 窗口：三类回答卡片计算样式一致，正文至少 16px、按钮至少 14px、导航至少 15px，复制按钮可达、无水平溢出，标题和提交按钮不被挤成竖排。
- 已查看最终包截图；窄窗口切换为上下布局，保留足够的回答区域及滚动访问。
- NSIS 安装器内 ASAR 和外置 JS/CSS 与验收包、当前构建逐项比对通过。主进程及预加载代码与 0.20.4 保持相同哈希。
- 本轮为定向回归，未重跑全部仓库测试；不将此前旧语音测试的失败宣称为已修复。
- 安装器没有 Authenticode 数字签名，可能出现未知发布者提示；哈希校验不等于数字签名。
